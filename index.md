## 1. Карта приложения (App)

Кода в репозитории пока нет — папка `App/` не создана. Раздел заполняется по мере разработки.

### Планируемая структура

```
App/
├── app/    # Next.js (React, TypeScript) — frontend магазина + dashboard
└── api/    # Express (TypeScript) + PostgreSQL — API
```

### Разделы dashboard

Не реализованы. Целевой состав — 8 табов аналитики, см. [docs/analytics-spec.md](docs/analytics-spec.md):
Дашборд, Выручка, Заказы, Доставка и далее по спецификации.

### Модели БД

Не реализованы. Referenced-схема из работающего проекта (`kaspi_stores`, `kaspi_orders`,
`kaspi_order_entries`) описана в [docs/kaspi-api-integration.md](docs/kaspi-api-integration.md).

### API-эндпоинты

Не реализованы. Внешние эндпоинты Kaspi, которые предстоит обернуть, — в
[docs/kaspi-api-integration.md](docs/kaspi-api-integration.md).

## 2. Карта документации (docs)

| Документ | О чём |
|---|---|
| [analytics-spec.md](docs/analytics-spec.md) | Спецификация аналитического модуля: принципы визуализации (Tufte / Few / Munzner), информационная архитектура из 8 табов, состав графиков и KPI. Источник правды для имплементации дашборда. |
| [kaspi-api-integration.md](docs/kaspi-api-integration.md) | Kaspi Shop API целиком: авторизация по `X-Auth-Token`, шифрование токена, эндпоинты заказов и позиций, стратегия синхронизации, маппинг полей, статусы заказов, схема БД, грабли. |
| [telegram-bot.md](docs/telegram-bot.md) | Telegram-бот: отправка сообщений и карточек-картинок заказа, маршрутизация получателям (поставщик / склад / доставка), уведомления об отменах и возвратах, cron и расписание, грабли. |

### Ещё не созданы

Создаются в момент первой записи, по правилу «новый код — сразу в документацию»
(п.9 и раздел «Фиксация изменений кода в docs/» в [AGENTS.md](AGENTS.md)):

- `api-reference.md` — эндпоинты `App/api`;
- `data-model.md` — таблицы, миграции, индексы;
- `app-structure.md` — страницы, маршруты, разделы dashboard, ключевые компоненты `App/app`;
- `deployment.md` — окружения, переменные, деплой;
- `architecture.md` — общая архитектура и связи между частями.
